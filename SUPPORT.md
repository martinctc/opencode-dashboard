# Support

Thanks for using OpenCode Usage Dashboard. Here is where to go for help.

## Questions and discussion

For questions, ideas, and general discussion, use
[GitHub Discussions](https://github.com/martinctc/opencode-dashboard/discussions).

## Bug reports

If something is broken, please
[open an issue](https://github.com/martinctc/opencode-dashboard/issues/new/choose)
using the bug report template. Helpful details include:

- the output of `opencode --version`,
- your operating system and Python version,
- the exact command you ran,
- the full error message, including any schema-validation error.

## Schema and compatibility questions

OpenCode's local database schema is an implementation detail and can change
between releases. If the exporter reports a missing table or column, see
[Compatibility and data format](https://martinctc.github.io/opencode-dashboard/docs/compatibility.html)
for the tables and columns it expects and how to point it at a custom database.

## Security issues

Do **not** report security issues in a public issue. See
[SECURITY.md](https://github.com/martinctc/opencode-dashboard/blob/main/SECURITY.md)
for how to report them privately.

## Documentation

The full documentation lives at
[https://martinctc.github.io/opencode-dashboard/](https://martinctc.github.io/opencode-dashboard/).
